# SCT_WD_4 — MyTaskApp 📝 To-Do List

A browser-based interactive To-Do application built with pure HTML, CSS, and JavaScript that enables users to add, organize, edit, and track tasks with due dates and priorities.

## Task Description

**TASK 04**
**TO-DO LIST APPLICATION**

Develop a basic to-do app that enables a user to add and maintain tasks. Allow users to add/organize items in lists, mark them Completed, Edit them, and Set Date & Time of tasks.

## Features

- Add tasks with a title, priority level, and due date & time
- Organize tasks into custom lists (e.g. Personal, Work, or any user-created list)
- Mark tasks as **Completed** with a single click on the checkbox
- **Edit** any task inline — update title, priority, and due date on the fly
- **Set Date & Time** for each task with a datetime picker
- Filter tasks by — All, Today, Pending, Completed, Overdue, or by List
- Filter by **Priority** — High, Medium, Low
- **Sort** tasks by latest added, priority, due date, or A→Z
- Overdue task detection with animated warning badge
- Real-time **Progress Bar** showing completion percentage
- Stats panel — Total, Done, and Remaining task counts
- Speed-friendly — press **Enter** to quickly add tasks
- Clear all completed tasks in one click
- Fully responsive layout for desktop and mobile
- Data persists across browser sessions using **localStorage**

## Tech Stack

- **HTML5**
- **CSS3** (custom properties, grid, flexbox, keyframe animations, gradient effects)
- **JavaScript** (DOM manipulation, localStorage, task filtering & sorting logic)
- **Google Fonts** — Poppins, Nunito

## How to Use

1. Type a task in the input field and press **Enter** or click **+ Add Task**
2. Choose a priority, list, and due date before adding
3. Click the **checkbox** on any task to mark it complete
4. Hover over a task to reveal **Edit ✏️** and **Delete 🗑️** buttons
5. Use the sidebar to filter tasks by view, priority, or list
6. Create new lists using the **+ input** in the sidebar under "My Lists"
